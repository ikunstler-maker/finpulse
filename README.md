# FinPulse

Бюджет за зарплатним циклом: що вже сплачено, що ще треба сплатити до наступної зарплати
(включно з платежами на початку наступного місяця) і скільки залишиться.

**Сайт:** https://ikunstler-maker.github.io/finpulse/

- Зарплата частинами й у валюті (USDT, $) з реальним курсом кожного виводу; підказка курсу НБУ і біржі.
- Групи витрат: прострочено, найближчі 7 днів, пізніше, до ЗП, сплачено; пошук, фільтри, сортування.
- Цілі-конверти, дві виплати (аванс + основна), звірка з банком, звіти.
- Дані — у браузері; за бажанням зашифровано паролем і синхронізовано через ваш Google Диск
  (лише прихована папка застосунку). Без серверів, реклами й аналітики.
- Працює без інтернету і встановлюється на головний екран.
