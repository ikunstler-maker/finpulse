# FinPulse — дорожня карта

Складено 29.10.2026 за розділом 9 `docs/playbook.md`. Ціни й ліміти конкурентів позначено «перевірити»:
їх треба звірити з актуальними сторінками сервісів перед будь-якими рішеннями.

## 1. Головна ідея
FinPulse планує гроші **за зарплатним циклом, а не за календарем**: показує, що вже сплачено, що ще
треба сплатити до наступної зарплати (включно з «містком» — платежами на початку наступного місяця)
і скільки реально залишиться. Він розуміє зарплату в USDT/валюті частинами з різним курсом і тримає
дані **у людини**: у браузері або зашифровано на її власному Google Диску, без серверів і реклами.

## 2. Порівняння з конкурентами
| Сервіс | Що добре | Чого бракує для нашого користувача | Ціна |
|---|---|---|---|
| Monobank (статистика) | Автоматичні витрати з картки | Немає плану на цикл ЗП, валютних виводів частинами, «містка» | Безкоштовно |
| Spendee | Гаманці, бюджети, спільні рахунки | Бюджет за календарем; дані в їхній хмарі | Підписка — перевірити |
| YNAB | Конверти, «кожна гривня має роботу» | Англійською, складний старт, дані в їхній хмарі | Підписка — перевірити |
| Monefy | Дуже швидкий запис витрат | Немає планування платежів і циклу ЗП | Безкоштовно / Pro — перевірити |
| Actual Budget | Відкритий код, локальні дані | Потрібен свій сервер для синхронізації, англійською | Безкоштовно / хостинг — перевірити |

## 3. Тарифи
- **Зараз і надалі безкоштовно:** усе, що є (бюджет, звіти, цілі, шифрування, синхронізація через
  Google Диск користувача). У FinPulse немає витрат на сервери, тому брати гроші за це немає причини.
- **Принцип:** безпеку й базову роботу не ховаємо за оплатою. Платним може бути лише те, що коштує
  грошей нам (наприклад, власний сервер для спільних бюджетів) або цінне великим командам.
- **ШІ та інші платні сервіси — підхід «принеси свій ключ»:** людина вставляє свій ключ API, ми не
  перепродуємо ресурси і не бачимо її даних.

| Q1 2027 | Відкриття для перших 10–20 людей | Скільки людей користуються другий місяць | Google перевірив застосунок; є сторінка допомоги |
| Q2 2027 | Спільний бюджет (пара/сім'я) без серверу | Кількість спільних бюджетів | Двоє бачать і змінюють один бюджет через спільну папку Диска |

## 6. Ризики і що з ними робимо
| Ризик | Що робимо |
|---|---|
| Людина втрачає пароль і ключ відновлення | Чіткі попередження; резервні копії; нагадування раз на місяць зберегти копію |
| Google змінює правила доступу до Диска або вимагає перевірку | Мінімальний доступ `drive.appdata`; готові сторінки політики; резервні копії працюють без Google |
| Джерела курсу (НБУ, WhiteBIT) змінюють API | Підказка необов'язкова; ручне введення завжди є; можна додати інше джерело |
| Конфлікти змін з кількох пристроїв | Новіша версія + копія іншої з відновленням; далі — злиття по записах |
| Безкоштовний хостинг GitHub Pages для комерційного використання | Перед монетизацією перевірити умови або перейти на інший хостинг |
| Права на код | Код власниці; перед роботою з компаніями — письмова домовленість |

      (вказати сторінки `privacy.html` і `terms.html`), за потреби — перевірка текстів юристом.
